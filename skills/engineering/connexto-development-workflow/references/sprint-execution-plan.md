# Legacy sprint execution plan reference

**Status: deprecated compatibility notice. This file is not an authoring template.**

Older workflow rules referenced this path as a sprint-plan template. That authority has been retired to prevent a generic skill template from competing with a target repository's normative planning rule.

When preparing a campaign sprint execution plan:

1. Read the target repository's `AGENTS.md` and always-applied project rules.
2. Use the exact canonical sprint-plan template designated by the target repository.
3. Follow the target repository's artifact-language policy for the plan, task cards, execution record, reports, and closeout.
4. If the target repository does not identify a canonical template or artifact-language policy, record the missing authority and mark dependent planning as `BLOCKED`. Do not fall back to this file or infer PT-BR.

The generic demand-level SDD artifact `plan.md` remains defined separately by [`templates/plan.md`](../templates/plan.md). It is not a campaign sprint execution plan.
